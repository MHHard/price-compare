# tea-price-compare 技术说明

这份文档承载实现细节，不作为产品需求或产品验收的替代品。

当前 MVP 只验收美团买券、外送、自取三种方式；京东代码保留，但不属于本轮主流程。

## 1. 当前实现结构

- Android App：`tea-price-compare`
- 包名：`com.mahao.teapricecompare`
- 本地收藏订单：JSON 文件。
- 页面操作：Android 无障碍服务。
- 模糊匹配和价格解析：DeepSeek API。
- 当前模型：`deepseek-v4-flash`

主要代码位置：

- `MeituanAutomator.kt`：美团搜索、进店、找商品、加购、购物车和结算流程。
- `MeituanSelectors.kt`：美团页面判断和 Tab/弹窗选择器。
- `MeituanRoute.kt`：买券、外送、自取路线及双模式价格数据结构。
- `PriceComparator.kt`：平台路线分发。
- `AccessibilityDumpActivity.kt`：真实设备调试入口。

## 2. 美团路线

当前路线：

- `VOUCHER`：美团买券。
- `DELIVERY`：美团外送。
- `PICKUP`：美团自取。

外送和自取共用：

`进入美团 → 点击外卖 → 搜索店铺 → 进入店铺 → 找商品 → 规格选择 → 加购 → 打开购物车抽屉`

进入抽屉后分别选择两个 Tab，读取两种模式的数据，再恢复发起本次查价的模式继续结算。

## 3. 规格弹窗分支

已抓到两种页面：

1. 有“加入购物车”：点击该按钮。
2. 没有“加入购物车”：只有默认规格和“关闭选规格”，关闭后视为默认规格已加购。

不能统一当成“点关闭”，也不能统一等待“确定”。

## 4. 购物车抽屉

当前设备实测的底部购物车入口约为：

`x=100, y=2260`

抽屉 Tab 当前实测区域约为：

- 外送：`x=230~310, y=1235~1290`
- 自取：`x=764~843, y=1235~1290`

实现优先按节点文字和所在区域识别，坐标只作为无障碍语义不足时的兜底。

## 5. 价格和状态

当前数据结构支持同时保存：

- 外送价格或错误原因。
- 自取价格或错误原因。
- 商家距离。
- 当前路线进入最终结算页后的价格。

需要区分：

- 商品小计。
- 优惠后价格。
- 配送费。
- 打包费。
- 起送差额。
- 最终应付价格。

“差 xx 起送”表示当前订单还不能直接下单，不能直接当成最终价格。

## 6. 模式不可用

当前通过商品文字中的“仅外送”“仅自取”等标记识别明显的模式限制。

如果切换 Tab 后没有形成有效购物车或结算状态，该模式保留错误原因，另一模式继续返回。

外送未达到起送价与商品不支持自取是不同状态，不能混为一个错误。

## 7. 距离

自取结果从店铺页读取“距您 xxxm/公里”文字，当前设备抓到的示例为：

`距您 904m`

没有读到距离时返回未知状态，不由模型或代码猜测。

## 8. 当前实现状态

已写入代码但仍需真实设备复测：

- 美团规格弹窗两种分支。
- 加购后打开底部购物车抽屉。
- 外送/自取 Tab 依次读取。
- 自取不可用时保留外送结果。
- 外送未达到起送价时保留自取结果。
- 自取价格和商家距离同时保留。

京东搜索链路已经实测稳定。淘宝和饿了么不纳入后续实现范围。
